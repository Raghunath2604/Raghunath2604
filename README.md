## About

I build **machine learning systems that go beyond experimentation** — from model development and evaluation to deployment, monitoring, automation, and production-oriented infrastructure.

My interests sit at the intersection of:

- **MLOps & LLMOps:** Reproducible pipelines, model lifecycle management, drift monitoring, and intelligent automation.
- **AI Engineering:** LLM applications, RAG systems, agentic workflows, and inference services.
- **Cloud-Native Engineering:** Docker, Kubernetes, FastAPI, CI/CD, and observability.
- **Reinforcement Learning:** PPO, SAC, TD3, simulation experiments, and sim-to-real robustness.
- **Data Engineering:** Feature pipelines, data validation, analytics, and model-serving infrastructure.

Currently building and improving **MLOps.dev**, an edge-focused ML deployment and management project.
